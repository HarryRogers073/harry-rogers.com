## Project Overview

A comprehensive telecommunications systems investigation and network architecture simulation engineered for the **Data Communications & Telecommunications** curriculum at the **University of Brighton**, taught by **Dr. Deshinder Singh Gill**.

The project investigates data communications across all seven layers of the OSI model using **Cisco Packet Tracer**, culminating in the design and critical evaluation of an advanced, multi-layered Wide Area Network (WAN). Beyond standard networking primitives, the research evaluates emerging telecommunications paradigms, specifically the transition from conventional packet-switched data connectivity to **RF Sensing** and **Channel State Information (CSI)** analysis using Software-Defined Radios (SDR).

## Key Network Implementations & Protocols

### 1. Secure Wireless Infrastructure (WPA2-PSK / AES)
Unlike standard open networks, enterprise-grade wireless security was configured on the Gateway router using **WPA2-PSK (AES)** encryption to protect over-the-air frame transmission from eavesdropping and packet injection:

![WPA2-PSK Wireless Security Configuration](/images/projects/communications/wpa2-security-config.png)
*Figure 3: WPA2-PSK (AES) pre-shared key authentication configured on the gateway, serving secured wireless endpoints.*

### 2. Layer 3 Serial WAN Routing (V.35 DTE/DCE)
To simulate a commercial T1 leased line across subnets, a remote Web Server (`10.2.0.10`) was deployed across a **Serial V.35 physical link**. The link was configured as a **DTE/DCE pair**, where the local gateway router acted as Data Circuit-terminating Equipment (DCE) providing clock synchronisation (`clock rate 64000`), and the remote gateway functioned as Data Terminal Equipment (DTE).

![Serial V.35 WAN Routing and RIP Configuration](/images/projects/communications/wan-serial-routing.png)
*Figure 4: Layer 3 serial routing table and RIP dynamic routing protocol exchange bridging distinct network segments.*

![HTTP Client Request across WAN](/images/projects/communications/wan-http-request.png)
*Figure 5: Verification of cross-subnet HTTP packet delivery across the serial link, confirming end-to-end packet delivery.*

## Advanced Theoretical Evaluation: From Data Connectivity to RF Sensing

A central component of this research is a critical evaluation of simulation fidelity versus physical electromagnetic reality. While simulation tools assume ideal deterministic bit transfers, real-world communications are governed by multipath fading, shadow fading, and electromagnetic interference.

### Channel State Information (CSI) & Software-Defined Radio (SDR)

Drawing on cutting-edge research led by **Dr. Muhammad Bilal Khan** at the University of Brighton, the report critiques how IEEE 802.11 Wi-Fi signals can be repurposed beyond data transport for **RF Sensing**:

- **Physical Wave Perturbation:** As radio frequency waves propagate through an environment, physical obstacles and human movements induce minute scattering, diffraction, and Doppler shifts.
- **CSI Extraction:** Whereas received signal strength indicators (RSSI) provide only coarse power amplitude, Channel State Information captures fine-grained phase and amplitude matrices across individual OFDM subcarriers.
- **SDR Integration:** Using Software-Defined Radios (such as USRP or HackRF), physical perturbations in CSI matrices can be classified via machine learning algorithms for human presence detection, respiration tracking, and non-line-of-sight gesture recognition without physical cameras or sensors.
