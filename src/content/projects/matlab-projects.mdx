## Project Overview

A consolidated collection of engineering instruments, digital signal processing (DSP) pipelines, and simulation tools built in **MATLAB & Simulink** across BEng coursework (EO631 & EO626) at the **University of Brighton**.

The repository bridges graphical desktop application design in **MATLAB App Designer**, low-level microprocessor architecture simulation, continuous-to-discrete filter synthesis via the **Bilinear Transformation**, and automated synthesizable **HDL IP core generation**.

---

## 🎛️ Digital Signal Processing (DSP) Filter Design

The suite includes mathematically rigorous digital filter synthesis using both IIR (Infinite Impulse Response) and FIR (Finite Impulse Response) methodologies:

| Filter Type | Order | Design Method | Passband Ripple | Stopband Attenuation | Phase Response |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Butterworth IIR** | 11th Order | Bilinear Transform with Frequency Pre-warping | Flat (0 dB) | -66 dB / decade roll-off | Non-linear |
| **Hamming Window FIR** | 324th Order | Sinc truncation with Hamming window tapering | ±0.05 dB | -53 dB | Perfectly Linear |

## 📦 Repository Structure & Modules

- **`app_designer/`**: Contains `.mlapp` standalone binary and source definitions for the Telemetry Dashboard and PIC16F84A CPU Explorer.
- **`dsp_filter_design/`**: Filter synthesis scripts (`Butterworth.m`, `Hamming.m`) and spectrum analysis plotting functions.
- **`simulink/`**: `Final_Model_2025A.slx` audio crossover simulation harness with dynamic interference injection.
- **`hdl_export/`**: Automated script invoking MATLAB HDL Coder to generate synthesizable VHDL/Verilog RTL cores from discrete filter objects.
