## Project Overview

A low-level bare-metal firmware library engineered in **pure MPASM Assembly Language** for the **Microchip PIC16F873** and **PIC16F84A** 8-bit Harvard architecture microcontrollers, developed for advanced embedded systems coursework at the **University of Brighton** and awarded an **84% Distinction Grade (A+)**.

The project focuses on register-level execution, cycle-accurate timing loops, interrupt servicing, and bus orchestration without relying on compiler abstractions or runtime overhead.

---

## Core Circuit: PIC16F873 Reference Design

The flagship hardware system pairs two PIC16F873 microcontrollers over a full-duplex hardware UART serial bus. The master controller samples real-time analogue/digital inputs and streams command packets to the slave controller, which dynamically computes PWM waveforms and drives high-power peripheral loads.

![PIC16F873 Core Circuit Schematic](/images/projects/pic/pic.png)

## System Specifications & Registers

| Feature | Hardware Implementation | Target Registers |
| :--- | :--- | :--- |
| **Microcontroller** | Microchip PIC16F873 (28-pin DIP, 20 MHz Crystal) | `PORTA`, `PORTB`, `PORTC` |
| **Serial Bus** | Hardware USART (Asynchronous 9600 Baud, 8-N-1) | `RCSTA`, `TXSTA`, `SPBRG`, `RCREG` |
| **PWM Output** | Hardware CCP1/CCP2 in PWM Mode with Timer 2 | `CCP1CON`, `CCPR1L`, `T2CON`, `PR2` |
| **Display Drivers** | Multiplexed Common-Cathode 7-Segment Hex Displays | Direct bit latching on `PORTB` & `PORTC` |
| **Interrupts** | RX Serial Interrupt & Timer Overflow ISR | `INTCON`, `PIE1`, `PIR1` |

## Assembly Firmware Modules

- **`16F873_RX_to_PWM.asm`:** Hardware UART packet reception triggering dynamic PWM duty-cycle modulation.
- **`16F873_RX_to_LEDs_PORTC.ASM`:** Direct byte latching and parallel register bit driving for visual diagnostics on Port C.
- **`PWM.asm` & `PWM_Simple.asm`:** Hardware Timer 2 (TMR2) and PR2 period registers for high-efficiency pulse modulation.
- **`SimplePWMTest.asm`:** Automated bench verification loop for pulse width integrity checking.
