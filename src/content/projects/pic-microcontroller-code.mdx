## Project Overview

A comprehensive bare-metal embedded firmware library developed across **EO631 (Embedded Systems 3)** and **EO524 (Embedded Systems)** modules at the **University of Brighton**, earning an **84% Distinction Grade (A+)**.

The codebase demonstrates cycle-accurate, register-level control of **Microchip PIC16F873**, **PIC16F84A**, and **PIC18** microcontrollers using both **MPASM Assembly** and **MPLAB XC8 Embedded C**.

---

## ⚡ Circuit Schematic: Master/Slave Dual PIC Architecture

The flagship hardware system pairs two PIC16F873 microcontrollers over a full-duplex hardware UART serial bus. The master controller samples real-time analog/digital inputs and streams command packets to the slave controller, which dynamically computes PWM waveforms and drives high-power peripheral loads.

## 🔬 System Specifications & Registers

| Feature | Hardware Implementation | Target Registers |
| :--- | :--- | :--- |
| **Microcontroller** | Microchip PIC16F873 (28-pin DIP, 20 MHz Crystal) | `PORTA`, `PORTB`, `PORTC` |
| **Serial Bus** | Hardware USART (Asynchronous 9600 Baud, 8-N-1) | `RCSTA`, `TXSTA`, `SPBRG`, `RCREG` |
| **PWM Output** | Hardware CCP1/CCP2 in PWM Mode with Timer 2 | `CCP1CON`, `CCPR1L`, `T2CON`, `PR2` |
| **Display Drivers** | Multiplexed Common-Cathode 7-Segment Hex Displays | Direct bit latching on `PORTB` & `PORTC` |
| **Interrupts** | RX Serial Interrupt & Timer Overflow ISR | `INTCON`, `PIE1`, `PIR1` |

## 📦 Firmware Modules in Repository

### 1. MPASM Assembly Routines (`firmware_asm/`)
- **`16F873_RX_to_PWM.asm`:** Hardware UART packet reception triggering dynamic PWM duty-cycle modulation.
- **`16F873_RX_to_LEDs_PORTC.ASM`:** Direct byte latching and parallel register bit driving for visual diagnostics.
- **`PWM.asm` & `PWM_Simple.asm`:** Hardware Timer 2 (TMR2) and PR2 period registers for high-efficiency pulse modulation.

### 2. Embedded C Drivers (`firmware_c/`)
- **`MovementCode.c`:** Dual H-bridge motor steering logic and velocity throttling.
- **`ultrasonic_driver.c`:** HC-SR04 sonar trigger generation and hardware timer capture interrupt routines for distance ranging.
- **`stepper_actuator.c`:** 4-phase step-sequencing driver for precision stepper indexing.
- **`lcd.c`:** Hitachi HD44780 4-bit/8-bit parallel character LCD display controller.
