## Project Overview

**VAIDAR** (*Verification & Artificial Intelligence for Digital Architecture Runtime*) is an automated **Hardware-in-the-Loop (HIL) verification execution engine** developed as my Final Year BEng Individual Dissertation Project (XE636) at the **University of Brighton**. 

The project achieved a **Final Distinction Grade of 91% (A+)** and was recognized with **The IET Prize 2026** by the Institution of Engineering and Technology.

Traditional FPGA verification relies heavily on manual bench testing with oscilloscopes and function generators, or slow software RTL simulation that can consume up to 70% of the hardware design lifecycle. VAIDAR bridges physical silicon with modern software testing by wrapping high-speed serial transports in an intuitive Python architecture and integrating LLM-assisted edge-case test generation.

## 🏗️ Architectural Composition

The software architecture is decoupled into three primary object-oriented tiers:

1. **The Orchestrator (`TestEngine`):** Coordinates test queues, handles execution timeouts, logs cycle performance, and reports anomalies.
2. **The Translator (`DeviceProfile`):** Encapsulates hardware bit widths and packs abstract test dictionaries into binary byteframes.
3. **The Operator (`CommDriver`):** Manages low-level byte transmission across the physical USB-UART bridge to the FPGA.

```verilog
// Target Hardware Silicon: AMD Xilinx Artix-7 (Nexys A7-100T)
// Top-Level ALU execution state machine
always @(posedge clk or posedge reset) begin
    if (reset) begin
        state <= IDLE;
    end else begin
        case (state)
            IDLE:      if (rx_ready) state <= LATCH_A;
            LATCH_A:   state <= LATCH_B;
            LATCH_B:   state <= EXECUTE;
            EXECUTE:   state <= TRANSMIT;
            TRANSMIT:  if (tx_done) state <= IDLE;
        endcase
    end
end
```
