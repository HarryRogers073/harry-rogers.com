## Project Overview

Developed for the **EO631 - Embedded Systems 3** engineering module at the **University of Brighton**, this project combines low-level assembly firmware for Microchip PIC microcontrollers with an interactive MATLAB App Designer host environment.

The project earned an **84% Distinction Grade (A+)**.

---

## 🎯 Key Capabilities

- **PIC16F84A Instruction Explorer:** Visual step-by-step instruction execution emulator written in MATLAB, displaying register file updates (W, STATUS, PORTA, PORTB), flag states, and cycle counts.
- **Multi-Channel Hardware Sensor Dashboard:** Real-time data acquisition, digital calibration, dynamic scaling, and threshold alert alarms across ADC input pins.
- **Hardware PWM Generation:** Assembly firmware routines utilizing hardware timers and prescalers for high-precision motor modulation and LED control.
- **JSON Configuration Schema:** Loadable sensor calibration profiles for rapid multi-sensor deployment.
