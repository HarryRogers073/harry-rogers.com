## Project Overview

As Co-President & VP of the **Brighton Real Ale Society**, I designed and engineered the official web platform serving society members, alumni, and committee executives.

The platform provides a modern digital hub for event schedules, real-time beer rating leaderboards, interactive committee voting, and historical pub crawls.

---

## 🏗️ Architecture & Pipeline

- **Frontend:** Next.js (React 19) App Router with server-side rendering, dynamic route handlers, and custom glassmorphism design system.
- **Backend & Database:** Supabase PostgreSQL instance accessed via Prisma Client ORM with connection pooling and session-mode migrations.
- **CI/CD Pipeline:** Fully automated deployments to **Vercel** with GitHub Actions branch testing and automated quality checks.
- **Security:** Bcrypt hashed credentials, session management, and zero secrets committed to source control.
