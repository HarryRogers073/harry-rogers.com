## Project Overview

A modular digital logic and FPGA hardware description library written in **IEEE standard VHDL**, developed for the **Digital Systems Design** curriculum at the **University of Brighton** and earning an **84% Distinction Grade (A+)**.

The repository implements synchronous finite state machines (FSMs), priority request arbitration queues, arithmetic sub-units (ALUs, ripple adders, multipliers, magnitude comparators), sequential shift registers, and seven-segment display decoders synthesised in **Intel Quartus Prime** and verified through gate-level timing simulations in **ModelSim**.

## Architecture Specifications: Multi-Floor Elevator Controller

| Subsystem Module | Entity Name | Description | Key Signals |
| :--- | :--- | :--- | :--- |
| **Main FSM Controller** | `Lift.vhd` | Finite state machine coordinating motor direction, floor arrival, and door sequencing. | `clk`, `reset`, `floor_req`, `motor_up`, `motor_down`, `door_open` |
| **Synchronous Queue** | `Queue.vhd` | FIFO/priority queue latching external floor calls and scheduling the shortest path. | `req_in`, `serviced`, `next_target` |
| **Door Actuator** | `doors_but_better.vhd` | Timed door cycle controller with safety obstacle pause and auto-retract. | `door_sensor`, `timer_done`, `door_state` |
| **Clock Prescaler** | `clock_div1.vhd` | Integer clock divider converting 50 MHz FPGA system clock down to 1 Hz visual update pulses. | `clk_50MHz`, `clk_1Hz` |
| **Display Decoder** | `bin2hex.vhd` | 4-bit binary to active-low 7-segment hex character mapping. | `data_in[3:0]`, `seg_out[6:0]` |

## Arithmetic & Sequential Building Blocks

In addition to the elevator system, the repository contains a library of synthesiseable digital logic primitives:

### 1. Arithmetic Units
- **`Adder_Sub.vhd`:** Selectable ripple-carry adder/subtractor with 2's complement logic and overflow detection.
- **`full_adder_vhdl_code.vhd`:** Structural 1-bit full adder primitive with carry propagation.
- **`bitMultip.vhd`:** Combinational binary multiplier array.
- **`Comp4.vhd`:** 4-bit unsigned magnitude comparator ($A > B$, $A = B$, $A < B$).
- **`Sub4.vhd`:** 4-bit dedicated binary subtractor.

### 2. Sequential Logic & Registers
- **`ShiftReg1.vhd`:** Multi-mode parallel-in serial-out (PISO) and serial-in parallel-out (SIPO) shift register.
- **`Counter.vhd`:** Modulo-$N$ synchronous up/down counter with asynchronous reset and terminal count flag.
